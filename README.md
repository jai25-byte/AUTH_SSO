A demonstration identity and access management project that provides a simple sign-in experience for employees and enterprise administrators. VaultAuth SSO demonstrates email and password authentication, mock OTP verification, role-based access, and session management.
Project type: Educational cybersecurity and frontend development project Duration: 4 weeks Track: PST_PD_154 — 2026 Level 4 (Stretch)
📌 Project Overview
VaultAuth SSO is designed to make the authentication journey simple and understandable. Users can register or log in, complete a mock OTP verification step, and access role-specific dashboards.
The project also includes an extended React Native mobile companion app concept featuring a Corporate Digital ID Card, employee credential badges, active sessions, and a session revocation action.
The main objective is to demonstrate how authentication, verification, and access restrictions work together in a user-friendly interface.
✨ Features
Web Application — Core Features
* User Registration: Register using an email address and password with form validation.
* User Login: Sign in using registered demo credentials.
* Password Hashing: Demonstrate password hashing before local storage.
* Mock OTP Verification: Complete a simulated one-time password verification step with success, failure, and retry feedback.
* Role-Based Access: Separate End User and Enterprise Admin views.
* Protected Dashboard: Restrict access to protected screens when signed out.
* Logout: Clear the active demo session and return to the login screen.
* Session Management: Display and manage sample session information.
* Responsive Design: Support phone, tablet, and laptop screen sizes.
* Form Feedback: Display validation errors, success messages, and unauthorized access messages.
