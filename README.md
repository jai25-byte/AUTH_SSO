# 🔐 VaultAuth SSO

VaultAuth SSO is a **cybersecurity project** focused on authentication, access control, and session management. We are building a simple web application that demonstrates how users can securely navigate a sign-in flow and access role-specific features.

## 🚀 What We're Building

- 🔑 **Registration & Login** — Email and password authentication with form validation.
- 🔢 **Mock OTP Verification** — A simulated second verification step.
- 👥 **Role-Based Access Control (RBAC)** — Separate views for End Users and Enterprise Admins.
- 🔒 **Session Management** — Login, logout, and demo session tracking.
- 📱 **Mobile Companion App** — A digital employee ID card, active sessions list, and session revocation using React Native and Expo Go.
- 🎨 **Responsive UI** — A clean interface for mobile and desktop.

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap 5
- React Native & Expo Go (mobile extension)
- Git & GitHub

## 🎯 Project Goal

Our goal is to understand authentication and access management by building a practical, beginner-friendly prototype while improving our frontend development and cybersecurity skills.

## ⚠️ Disclaimer

This is an **educational demo**, not a production authentication system. It uses sample data and client-side logic. Do not use real passwords, personal information, or production credentials.
